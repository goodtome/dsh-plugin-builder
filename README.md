# DSH 插件打包工具（Mac 首版）

双击 [`dist/DSH Plugin Builder.app`](dist/DSH%20Plugin%20Builder.app) 打开。选择含 `package.json` 的 DSH 插件源码目录，再选输出目录，可编辑「插件包名称」。先点「预览文件」，再点「生成插件包」。工具自动补 `.tgz` 后缀；默认名称来自插件包名和版本。同名插件包或配套文件已存在时会提示改名，不覆盖已有文件。无需在终端执行构建或打包命令。当前应用面向 Apple Silicon Mac，内置 Node、npm 和 pnpm，并使用临时副本处理源码，不修改原目录。

生成三个文件：`.tgz` 插件包、`.sha256` 校验文件、`.report.json` 检查报告。打包完成后，工具扫描 `/Applications` 和 `~/Applications` 中带内置 DSH Desktop 插件管理命令、且已初始化 Desktop Profile 的客户端。选择目标并点击「安装到所选客户端」，确认后由该客户端自带的运行时安装插件，无需再打开插件安装页面。也可使用「复制安装路径」手动导入。

直接安装前请完全退出目标客户端。工具会显示目标 Profile 路径，校验插件包未被修改，并在安装后核对包内名称与版本。目标已安装同名插件时，安装会停止并提示先在该客户端卸载旧版；不会自动卸载或覆盖。安装可能下载依赖和运行安装脚本。完成后重新打开客户端使用插件。扫描范围外的客户端仍可用复制路径方式导入。

「插件包名称」只修改外层 `.tgz` 文件名。DSH 按包内 `package.json` 的 `name` 识别插件；如果同名插件已安装，需先在 DSH 插件管理页面卸载旧版，再粘贴新包路径安装。若想让两款插件并存，必须在源码里调整包名、DSH patch 的模块引用和相关资源标识，并重新验证，单纯重命名压缩包无效。

## 支持范围

- 已具有 `dsh.bundle.patch` 的 DSH 插件源码。支持已有 JS 产物，以及提供 `build` 脚本的 TS 和前端插件。
- `npm` 项目使用内置 npm；声明 `packageManager: pnpm@...` 的项目使用内置 pnpm。请确保项目与内置版本兼容。
- 默认在临时副本中运行项目的 `build` 脚本。界面会明确询问是否允许执行该脚本。缺少构建依赖时，可选「自动安装构建依赖」，需要联网，依赖安装脚本保持禁用。
- 普通项目源码不会自动转换成 DSH 插件。若缺少包声明、patch 或入口，界面显示具体缺项。
- `.tgz` 可能仍需要 DSH 在安装时联网获取依赖。原生模块需要在目标 Mac 架构上自行验证。

## 检查与限制

预览使用 npm 的发布文件清单，显示文件、大小、依赖来源，以及可能包含凭据的文件。发现敏感文件时阻止生成。若选择运行构建，预览反映的是构建前的文件；生成时会再次检查最终归档。预览中的注册表、Git/URL 和本地计数来自 `package.json`，实际下载地址由项目配置决定。

生成时校验包名、版本、patch YAML、入口文件、输出目录和归档路径，并拒绝工作区或本地路径依赖。应用不会运行项目的 `prepare`、`prepack`、`postpack` 脚本。生成日志显示准备、依赖安装、构建、归档和验证阶段；失败时显示阶段及命令输出。此时报告仅表示包结构和入口检查通过。

可选「验证 DSH 加载」会在临时 Web Profile 安装该 `.tgz`，组合配置，并启动 DSH Web Host。验证需要已构建的 DSH CLI `bin.js`。应用会从所在仓库自动查找，独立运行时可手动选择。验证前应用会询问是否运行插件代码，结束后停止 Host 并删除临时 Profile。验证成功会写入 `.report.json` 的 `runtimeCheck` 字段。此项没有检查浏览器中的插件交互，也不保证用户实际 Desktop Profile 中的行为。

「仅使用本地依赖缓存」默认开启。若本机缓存缺少安装所需的依赖，临时验证会失败；关闭后允许 DSH 安装过程联网获取依赖。验证使用临时 DSH Profile，不卸载或升级用户已安装的插件。工具只检查几个常见 Desktop Profile 中的同名插件；其他 Profile 需在 DSH 中确认。

此版 `.app` 使用本地临时签名，未公证，也未制作安装镜像。供本机开发和验证使用。向其他 Mac 分发前需要正式开发者签名、公证及目标机验证。

## 开发维护

源码在 `src/`，本地回归在 `test/`。开发机运行 `node --test test/core.test.cjs`；构建应用时运行 `node package-mac.cjs`。打包脚本从本仓库已安装的 DSH Electron 复制运行时，生成 `dist/DSH Plugin Builder.app`。`.runtime/`、`node_modules/`、`dist/` 均为本工具的本地生成物，不提交 Git。
